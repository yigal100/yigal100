# Agent Skills (`.agents/skills/`)

This directory follows the open standard for Agent Skills.

## Purpose

Tools, skill manifests, and CLI helpers defined here provide coding agents with direct capabilities to interact with and automate this repository.

## Skill Structure

Each skill should be structured in its own subfolder:

```text
.agents/skills/<skill-name>/
├── SKILL.md         # Instructions and specification for the agent
└── ...              # Supporting scripts, templates, or CLI hooks
```
